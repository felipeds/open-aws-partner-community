# Brazil chapter (founding)

The founding chapter of the Open AWS Partner Community. Runs its own council,
backlog, and working groups with local autonomy, contributing to the single shared
codebase (reference §6, §7.6).

## Council

One council member per founding partner (plus a named alternate, §7.2). Cadence:
bi-weekly, 45 minutes by default (§7.1). Quorum: ≥75% of partner seats (§7.9).
